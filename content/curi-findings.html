Results from the attention run

Attention-based cache eviction failed the retrieval test.

The run expected a policy based on cumulative attention to degrade gradually as its cache shrank. At half the cache budget, it instead failed to retrieve the isolated facts needed by later questions, matching the random-eviction control.

50% cache budget · 0.5B model · three samples · verdict: bounded. This contradicted the run’s initial hypothesis. It reproduces a known limitation of attention-based retention; the small experiment does not establish a general result.

Other findings from the same run

ExperimentObserved result
Speculative decodingSlower than ordinary autoregressive decoding despite 38–54% draft acceptance. In this setup, accepting many guesses did not make up for their execution cost.
KV-cache quantizationAsymmetric K-INT8 / V-INT4 retained retrieval with four-bit values. Key and value quantization affected the attention calculation differently.
Randomized-Hadamard rotationDid not prevent key-quantization damage. The run retained this failed hypothesis as a refuted outcome.
